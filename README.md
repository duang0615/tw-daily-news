# 台股每日新聞彙整

> AI煉金術系列 · 堂 1「打造你的移動交易室」收尾作業 2
> 星系投資 AI墨達人 × 麥可鄧 · 教方法，非投資建議

把六個台股新聞來源彙整成一份**可以搜尋的標題列表**，每天早上 08:00 自動更新。

**線上看成品 →** https://duang0615.github.io/tw-daily-news/

---

## 這是什麼

一支 Python 腳本，每天做四件事：

1. **抓** — 證交所、櫃買、期交所、鉅亨網、MoneyDJ、DigiTimes
2. **整** — 三種格式併成同一張表，去重、濾掉舊聞與模板文
3. **印** — 產出 `index.html`（給你看）和 `news.json`（給 AI 讀）
4. **貼** — 把入口卡片塞回你自己的總頁（`--no-hub` 可以關掉）

頁面是**完全自包含**的靜態 HTML：CSS 和 JS 全部內嵌，沒有任何 CDN、沒有外部資源。
放 GitHub Pages、放 NAS、放隨身碟、直接用瀏覽器開檔案，都一樣會動。

搜尋、分類、來源篩選全部在瀏覽器本機跑，**不需要架伺服器**。

## 自己跑起來

只用 Python 標準函式庫，**不用 `pip install` 任何東西**。

```bash
git clone https://github.com/duang0615/tw-daily-news.git
cd tw-daily-news

python build_news.py --dry-run    # 先只抓不寫檔，確認九個來源都通
python build_news.py --no-hub     # 確認沒問題再正式產出
```

打開 `index.html` 就是成品。

| 參數 | 作用 |
|---|---|
| `--dry-run` | 只抓不寫檔，用來檢查來源通不通。**第一次跑一定先用這個** |
| `--no-hub` | 只產列表頁，不去動上一層的總頁 |
| （不加參數） | 產出頁面，並把入口卡片塞進 `../index.html` |

## 資料來源

**驗證日期：2026-09-15**，每一個都實際抓過。

| 來源 | 取得方式 | 狀態 |
|---|---|---|
| 證交所·新聞 | OpenAPI (JSON) | ✅ |
| 證交所·重大訊息 | OpenAPI (JSON) | ✅ |
| 櫃買·重大訊息 | OpenAPI (JSON) | ✅ |
| 期交所·公告 | 官方 RSS | ✅ |
| 期交所·新聞稿 | 官方 RSS | ✅ |
| 鉅亨網·台股 | 官方 RSS | ✅ |
| 鉅亨網·頭條 | 官方 RSS | ✅ |
| MoneyDJ | 原生 RSS **已停用** → Google News 代打 | ⚠️ |
| DigiTimes | 原生 RSS **需登入** → Google News 代打 | ⚠️ |

### 這份專案真正想教的一件事

我去打這六家，結果是：**四家有官方管道，兩家的 RSS 已經死了。**

- MoneyDJ 的 `/KMDJ/RSS/` 整區變成 404 錯誤頁
- DigiTimes 的 RSS 網址還在，但要會員登入，匿名抓回來是 404

而且——**這兩家的錯誤頁都是用 HTTP 200 回你的。**

所以：**狀態碼 200 不等於成功。** 判斷成功要看內容（有沒有 `<item>`、是不是合法 JSON），
不是看狀態碼。網路上任何一篇「台股 RSS 大全」抄下來直接用，都會踩到這個。

**先驗證，再寫程式。**

死掉的來源怎麼救——Google News 的站內搜尋 RSS：

```
https://news.google.com/rss/search?q=site:moneydj.com+when:2d&hl=zh-TW&gl=TW&ceid=TW:zh-Hant
```

把 `site:` 換成任何網域就行。這招對**任何沒有官方 RSS 的網站**都有效，
是這份專案裡最值得記住的一行網址。

## 其他踩過的坑

| # | 坑 | 解法 |
|---|---|---|
| 1 | 狀態碼 200 不等於成功 | 看內容，不看 status code |
| 2 | 重大訊息是每日快照，不是即時流 | 標成 `snapshot`，不套時間窗，否則連假整區空掉 |
| 3 | 民國年 `1150914` + 獨立的 `發言時間` 欄位 | `+1911`，時間要另外併，不然全部變 00:00 |
| 4 | 證交所 JSON 欄位名是 `"主旨 "`，**尾端有空格** | 讀進來先把所有 key `.strip()` |
| 5 | 期交所 RSS 的 `<link>`／`<pubDate>` 夾滿換行 | 所有欄位一律壓成單行 |
| 6 | 新聞灌在總頁上會又長又吵 | 總頁只放一張卡當入口，內容收進列表頁 |
| 7 | 列表頁放摘要就滑不完 | 人看的頁面只放標題，摘要留在 `news.json` 給 AI |

## 自動更新

`.github/workflows/daily.yml` 每天 UTC 00:00（台灣 08:00）跑一次，
有變動才 commit。也可以在 Actions 頁面手動觸發。

> **為什麼是 08:00**：開盤前你會看手機。前一晚的重大訊息、法人動向、
> 國際盤消息，這時候都已經落地了。

## 改成你要的樣子

| 想改什麼 | 改哪裡 |
|---|---|
| 加／減來源 | `SOURCES` 清單 |
| 過濾垃圾標題 | `NOISE` 正則清單 |
| 收多久以內的新聞 | `MAX_AGE_H` |
| 每個來源收幾則 | `PER_SOURCE` |
| 版面、配色 | `CSS` 字串 |
| 搜尋／篩選行為 | `JS` 字串 |

抓資料和畫版面是分開的，改版面不會動到抓資料的部分。
